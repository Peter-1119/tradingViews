# 畫圖

水平線、趨勢線、斐波那契、矩形和量測手勢，以及顏色、隱藏和撤銷。成交量分布工具在[關鍵價位與成交量分布](levels.zh-TW.md)。

## 繪圖存在哪裡

- **依幣種儲存，不依卡片也不依週期。** BTCUSDT 上的水平線會出現在每一張 BTCUSDT 卡片上，1 分、15 分、1 日切來切去都在。相同價格的線會自動去重。
- **現貨與永續共用。** 水平線、趨勢線、斐波那契、矩形和區間成交量分布都依幣種儲存、不分市場：BTCUSDT 現貨和永續的價差通常只有萬分之一、二，同一個支撐位在兩邊都成立，撤銷紀錄也跟著保留。報價放大過的合約（`1000PEPEUSDT`）本來就是不同的幣種，各自有自己的線，價格差了一千倍，本來就不能共用。
- 斐波那契的錨點、趨勢線的端點和矩形的角存的是 **{時間, 價格}**，不是 K 棒索引。索引只在目前載入的資料範圍內有意義，換個週期就指到別的 K 棒。

## 水平線

| 動作 | 方式 |
| --- | --- |
| 新增 | 在圖上空白處**雙擊**，任何模式都可以（按 `Ctrl` 吸到最近的 OHLC）。或選水平線工具後點一下 |
| 移動 | 拖曳線本身（按 `Ctrl` 吸附） |
| 刪除 | 雙擊線本身 |

## 趨勢線

選**趨勢線**（斜線圖示），從一點**拖曳**到另一點，或**各點一下**兩個端點（中間線會跟著滑鼠，`Esc` 取消）。畫出來的是兩點之間的實心線段，不延伸成射線。

- 按 `Ctrl` 吸附 OHLC。按住 `Shift` 畫成**水平線或垂直線**，依滑鼠移動較多的方向決定；拖端點、拖整條線時同樣適用，而選了趨勢線工具時 `Shift` 不再是量測。
- 拖端點調整、拖線身整條移動、雙擊刪除。

## 斐波那契回撤

選斐波那契，在圖上拖曳畫出波段。拖兩端的圓點可以調整，雙擊圓點刪除。回撤比例線橫跨整個圖表寬度：在這麼小的卡片上，你想知道的是「現在價格距離這些位置多遠」。

## 矩形

選矩形，拖曳畫出一個有起訖時間的價格區間。

- **拖邊框**移動、**拖角**調整大小（對角固定）、**雙擊**刪除。
- 拖曳途中按住 `Shift` 會鎖定方向：拖角只改寬度（時間）或只改高度（價格），拖邊框只水平或只垂直移動。
- 內部刻意不能抓，所以在框裡照樣可以平移圖表。

## 量測

按住 `Shift` 拖曳：顯示價差、百分比、K 棒數和時間長度。加按 `Ctrl` 吸到 OHLC。放開後讀數會留著，點一下空白處或按 `Esc` 清除。

量測主要是一個手勢，跟 TradingView 的快速量測一樣，因為在這種尺寸的卡片上手勢不佔畫面空間；工具列的量測按鈕是給還沒學會手勢的人用的。量測框以 K 棒座標而不是像素定位，所以平移縮放時會跟著 K 棒走，也能放在最後一根 K 棒右邊的空白處。

## 線條顏色

在水平線、趨勢線或矩形上按**右鍵**，跳出一排顏色：預設藍、**綠**（支撐）、**紅**（壓力）、橘、黃、紫、白，例如週線級的位置和日內的位置用不同顏色。目前的顏色有外框標示。顏色跟著那條線存起來（重開、換週期、現貨和永續都一樣），`Ctrl+Z` 可以撤銷。在其他地方按右鍵，一樣是打開設定面板。

## 隱藏繪圖

工具列的**眼睛**圖示（或 `Alt+H`）一鍵把水平線、趨勢線、斐波那契、矩形和區間成交量分布全部藏起來，看乾淨的盤面；再按一次就全部回來。

- 只是**不畫**，不會刪除，狀態也存在卡片設定裡（重開還是隱藏）。
- 隱藏時線也抓不到，不會拖到看不見的線。隱藏中拿起畫圖工具、新增水平線或按 `Ctrl+Z` 會自動顯示，免得新畫的線一放手就消失。
- 價格提醒、持倉 / 掛單線、開盤價和高低點不算繪圖，照常顯示。

## 撤銷

`Ctrl+Z` 撤銷水平線、趨勢線、斐波那契、矩形和區間成交量分布的新增、移動、改色和刪除，例如拉時間軸時不小心拖到線。每張卡片各自記錄，切換幣種會清空。
