# 提醒

三種：**價格**提醒、**成交量**提醒，以及告訴你價格落在最近成交量分布哪個位置的**位置提醒**。掛單成交和止盈止損觸發也會通知，見[下單](trading.zh-TW.md#成交通知)。

全部都不出聲（依需求）。每一種怎麼送到你面前，包括玩遊戲的時候，見[本頁最後](#通知怎麼送到)。

## 價格提醒

| 動作 | 方式 |
| --- | --- |
| 設定 | 點工具列的**鈴鐺**，再點圖上的價位（按 `Ctrl` 吸附 OHLC）；或滑鼠在圖上直接按 `Alt+A` |
| 方向 | 高於現價是「漲到」提醒，低於現價是「跌到」提醒 |
| 移動 | 拖曳金色虛線的標籤 |
| 刪除 | 點標籤上的 ✕ |

到價時送出 Windows 通知（不出聲）並閃爍工作列，依位置提醒的通知設定；每個提醒響一次後自動移除。

提醒由隱藏的資料視窗監聽，所以**卡片用 `Ctrl+Alt+S` 隱藏、甚至關掉時也會提醒**。只監聽有掛提醒的幣種。

## 成交量提醒

同一個鈴鐺（或 `Alt+A`），改點在**成交量柱**上而不是 K 線上；鈴鐺啟用時，滑鼠移到量柱區會出現金色標籤顯示該處的量。

- 當前週期的**單根 K 棒**成交量（USDT）第一次達到就通知，然後自動移除。
- 設得比目前這根的量還低時，不會立刻響，而是從下一根開始算。
- 提醒線只在設定時的週期顯示。拖曳標籤可調整，點 ✕ 刪除。

## 位置提醒

常用清單（☆）裡的幣種，圖表左上角會顯示目前價格在最近 **4H / 24H / 72H** 成交量分布中的位置，例如 `4H 17 · 24H 34 · 72H 23`：那段時間的成交量有多少比例成交在目前價格以下。顏色：80% 以上橘、95% 以上紅、20% 以下淺藍、5% 以下藍。

碰到設定的等級時，卡片邊框發光、跳 Windows 通知、工作列閃爍；**點一下卡片**清除。等級在設定面板「位置提醒」的勾選表調整。

| 開關 | 位置 |
| --- | --- |
| 總開關 | 系統匣右鍵 →「位置提醒」 |
| 個別幣種 | 系統匣 →「提醒的幣種」，或幣種清單（點幣種名稱）每列的 🔔 / 🔕 |

總開關與該幣種都開著才會通知。關掉的幣種照樣顯示百分比，重新打開時也不會補發關閉期間的提醒。

- **即時**：分布每根 1 分 K 棒收盤重算一次；目前價格用即時報價（最快每 100ms）對照，所以價格**碰到**等級就提醒，不是等收盤。實測只看收盤會漏掉 15～30% 的觸及。
- **遲滯（像施密特觸發器）**：每個等級響一次，上方（80 / 90 / 95）要回到 50% 以下才重新啟用，下方（20 / 10 / 5）要回到 50% 以上。一次跳過好幾個等級只報最遠的那個；App 啟動時已經在 92% 也不會一開就報 80、90。
- **預設等級**和實測頻率（每個幣每天）：24H 與 72H 全部六個等級，約 8.5 次與 2.7 次；4H 只開 5% 和 95%，約 11 次（4H 全開一天約 45 次，太吵）。
- **在背景監控**：沒開卡片也照樣由 hub 監控常用清單的幣種，每個幣保留 72 小時的 1 分 K 棒。

> **這不是進場訊號。** 同一份資料裡，價格在 90% 以上之後 4 小時下跌的機率是 44～57%，兩個幣、三個區間的方向都不一致。它的用途是提醒你「現在在分布的哪裡」，避免沒注意就追在最差的位置。

為什麼百分比是直接從分布數出來、而不是擬合一條曲線，見[分析指標](../design/analytics.zh-TW.md#位置提醒)。

## 通知怎麼送到

| 訊號 | 無邊框視窗的遊戲 | 全螢幕遊戲 |
| --- | --- | --- |
| 卡片邊框發光 | 看得到 | 看不到 |
| Windows 通知 | 被「專注輔助」收進通知中心（實測 Warcraft III 開著時沒有橫幅） | 看不到 |
| 工作列閃爍 | 卡片暫時有工作列按鈕，點卡片就停 | 看不到 |

都不會出聲。為什麼全螢幕遊戲時什麼都看不到、可以怎麼辦，見[卡片消失排查](../troubleshooting/vanishing-cards.zh-TW.md)的情況 G。
